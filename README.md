## Publicação — GitHub Pages

O GitHub Pages deve estar configurado para publicar a partir de:

1. Acesse **Settings** no repositório.
2. Entre em **Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch principal (`master` ou `main`, conforme a configuração do repositório).
5. Selecione a pasta **/docs** e salve.

Após o deploy, o portfólio ficará disponível no endereço institucional informado acima.
