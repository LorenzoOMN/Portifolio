# Portfólio Lorenzo — experiência single-page

Portfólio pessoal em uma única viewport, sem rolagem e sem framework.

## Navegação
- A navegação principal é feita por botões.
- Menu lateral no desktop e menu completo no mobile.
- Botões de CTA direcionam entre as telas.
- O scroll do mouse e o swipe NÃO controlam a troca de telas.

## Transição
A troca de telas usa uma camada de material compartilhado: elementos da tela atual viram pequenos fragmentos, esses fragmentos atravessam a interface e se reorganizam nos pontos da próxima tela. Há também uma passagem de três painéis para dar sensação de carregamento.

## Tecnologias
HTML5, CSS3 e JavaScript puro. Google Fonts é usado apenas para tipografia.

## Personalização imediata
1. Troque `SEU_EMAIL_AQUI` no `index.html`.
2. Atualize links sociais reais quando quiser.
3. Adicione imagens/vídeos reais aos projetos na área de projetos.
4. O conteúdo foi escrito para refletir a trajetória e os projetos conhecidos do portfólio; revise nomes/datas antes de publicar.
